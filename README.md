# Aurum Site

Игровой сайт сообщества Aurum. Репозиторий отделён от административной Aurum Panel: игровые аккаунты, сессии и права не смешиваются с персоналом панели.

## Текущий этап

В `apps/web` находится интерактивный визуальный прототип первого экрана после входа, страницы привязки Minecraft и переключателя темы. Все данные на экранах демонстрационные. Регистрации, реальной привязки, базы данных и деплоя пока нет; кнопка подтверждения кода намеренно неактивна.

Локальный запуск: Node.js 22+, pnpm 11, `pnpm install`, `pnpm dev`. Проверка сборки: `pnpm build`.

## План границ системы

- `apps/web`: React/Vite, интерфейс игроков.
- `apps/api` (следующий этап): отдельный Node API и PostgreSQL для учётных записей сайта, приватности, друзей, лент, комментариев и модерации.
- Minecraft/Paper: одноразовый код привязки выдаётся только авторизованному игровому игроку. Сайт получает подтверждение через узкий закрытый мост; административные токены Aurum Panel не используются.
- AurumGuilds и AurumCore остаются источником истины для членства, рангов и балансов. Сайт хранит лишь собственные социальные данные и запрашивает ограниченные действия с проверкой прав на стороне игры.
