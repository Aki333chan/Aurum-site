# Aurum Site

Игровой сайт сообщества Aurum. Репозиторий отделён от административной Aurum Panel: игровые аккаунты, сессии и права не смешиваются с персоналом панели.

## Текущий этап

В `apps/web` находится интерактивный визуальный прототип: глобальная главная с выбором игры и общей лентой, отдельное пространство Minecraft с гильдиями, личная страница, экран привязки и светлая тема. Все данные демонстрационные. Регистрации, реальной привязки, базы данных и деплоя пока нет; кнопки подтверждения кода и выхода намеренно неактивны.

Скриншоты одинаковых экранов: [главная 16:9](docs/previews/home-16x9.png) и [9:16](docs/previews/home-9x16.png); [Minecraft 16:9](docs/previews/minecraft-16x9.png) и [9:16](docs/previews/minecraft-9x16.png). Отдельно: [открытое мобильное меню](docs/previews/menu-9x16.png) и [светлая тема](docs/previews/home-light-16x9.png).

Навигация: «Главная» — общая лента и карточки игр; «Серверы» — каталог игровых миров. Minecraft Community открывается из карточки сервера. Его «Обзор» и «Гильдии» — вкладки внутри страницы сервера, а не отдельные пункты общего меню.

Локальный запуск: Node.js 22+, pnpm 11, `pnpm install`, `pnpm dev`. Проверка сборки: `pnpm build`.

## План границ системы

- `apps/web`: React/Vite, интерфейс игроков.
- `apps/api` (следующий этап): отдельный Node API и PostgreSQL для учётных записей сайта, приватности, друзей, лент, комментариев и модерации.
- Minecraft/Paper: одноразовый код привязки выдаётся только авторизованному игровому игроку. Сайт получает подтверждение через узкий закрытый мост; административные токены Aurum Panel не используются.
- AurumGuilds и AurumCore остаются источником истины для членства, рангов и балансов. Сайт хранит лишь собственные социальные данные и запрашивает ограниченные действия с проверкой прав на стороне игры.
