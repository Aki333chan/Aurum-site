# Экран входа и регистрации

- По умолчанию открывается вход; ссылка «Нет аккаунта? Зарегистрируйтесь» ведёт на отдельную форму регистрации.
- Регистрация требует подтверждения email по письму. После этого игрок входит обычным способом. `/aurumlink` появится позднее и привяжет уже зарегистрированный аккаунт к профилю Minecraft.
- Восстановление пароля и повторная отправка письма доступны без входа. Ошибки подключения отображаются явно; отсутствие API не считается успешным действием.
- Слева краткое описание Aurum и Minecraft Community, справа — одна форма с ясным главным действием. На узком экране форма располагается первой.
- Переключатель светлой и тёмной темы доступен до авторизации. После входа переключатель остаётся в левом меню.
- Лента свежих новостей на экране входа появится только вместе с настоящим источником данных; придуманную «последнюю новость» не показывать.
- 2FA сейчас не активна. Позже предложить включить её ненавязчиво после первого входа и в настройках безопасности, без блокировки обычных игроков.
