# Aurum Site — first signed-in screen (draft)

## Purpose and audience

The first signed-in screen must orient a player toward their game server and Minecraft identity link, then expose news and guild discovery. A player may be new, unlinked, or returning. This draft depicts the new, unlinked state; all preview content is visibly labeled as demonstration data.

## Direction contract

**Name:** Community foyer. Familiar Aurum Nocturne palette, but warmer and less administrative. One prominent Minecraft server surface is the dominant object; the identity-link path is immediately understandable. News and guild access remain within the first screen. No fictional balances, counts, or online server claims.

**First viewport:** Top identity bar, narrow left navigation, greeting, large Minecraft server card in the main column, and a compact right rail explaining the three-step link flow. The guild entry appears beneath it. Strong hierarchy: server first, link second, guild/news third. The server card carries abstract block-world geometry, not an invented screenshot or data.

**Signature interaction:** A player clicks “Привязать профиль,” sees the three in-game steps and the one-time code field. The field is intentionally non-submitting until the secure API exists. The theme toggle works in this prototype.

**Visual grammar:** Inter, restrained dark neutrals, Aurum gold for game identity, panel violet for active navigation and primary actions; one consistent rounded control vocabulary. Useful focus states and mobile reflow. Reduced-motion preference is respected.

**Risk to inspect:** The server card may read as too promotional. If so, reduce the abstract art and elevate the account-state summary. The right rail may feel dashboard-like; a tighter stacked mobile presentation should preserve the social character.

## Boundaries

This is a code-native visual prototype, not the public site. It has no authentication, no API request, no real guild or server data, and no deployed route. Backend functionality follows visual feedback and security design.
